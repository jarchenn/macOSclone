Aurora OS 0.1.0
Architecture: x86-64 (single CPU), QEMU "pc" reference machine.
Boot: Limine 12.9.3, Limine boot protocol base revision 6, UEFI or BIOS.

Kernel: freestanding C11, higher-half, own GDT/IDT, bitmap physical page
allocator, 4-level page tables with W^X and NX, bounded kernel heap,
8259 PIC + PIT timer, PS/2 keyboard and mouse.

Desktop: software compositor with damage tracking, window manager,
menu bar, dock, built-in Terminal, Files, Notes and Settings.

Limitations of release 0.1:
- Apps are built into one kernel address space. They are not isolated
  processes and a fault in an app stops the whole system.
- /home is a RAM filesystem: files are stored in memory and reset when
  Aurora restarts. /system is read-only.
- No networking, audio, USB, SMP, persistent storage or user accounts.
