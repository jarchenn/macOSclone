Aurora OS 0.7
Architecture: x86-64 (1 to 16 CPUs), QEMU "pc" reference machine.
Boot: Limine 12.9.3, Limine boot protocol base revision 6, UEFI or BIOS.

Kernel: freestanding C11, higher-half, own GDT/IDT, bitmap physical page
allocator, 4-level page tables with W^X and NX, SMP with a big kernel
lock, preemptive user processes with fork/exec, signals, threads, pipes,
pseudo-terminals, shared memory and local message sockets.

Desktop: a user-space display server (software compositor with damage
tracking, server-side decorations, a separate cursor layer, clipboard,
keymaps) and Terminal, Files, Notes and Settings as separate processes.
Text is TrueType (DejaVu) rendered with stb_truetype.

Limitations:
- /home lives on a virtio data disk when one is attached; otherwise it is
  a RAM filesystem that resets when Aurora restarts. /system is read-only.
- No audio or USB, one monitor, no GPU acceleration. Tested only in QEMU.
